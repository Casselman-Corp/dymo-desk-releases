Setting up DYMO Print Desk

You only do this once. After that, opening it is a double-click.

Which computer?

01

Install it

Windows

Download DYMO-Print-Desk-Setup.exe and double-click it.

It installs itself and puts a shortcut on your desktop. There is nothing to choose.

Mac

Download the .dmg file and double-click it.

A window opens showing the app icon next to an Applications folder. Drag the icon onto the folder, then close the window.

Two Mac downloads are offered. Choose Apple silicon for any Mac from 2020 onward, or Intel for older ones. To check: Apple menu → About This Mac. If it mentions M1, M2, M3 or M4, you want Apple silicon.

02

Get past the security warning

This warning is expected, and it appears only once. It shows up because the app doesn't carry a paid security certificate yet — not because anything is wrong with it.

Windows

A blue box says “Windows protected your PC.”

  1. Click More info — small text inside the box, easy to miss.
  2. Click Run anyway.
Mac

A box says the app “could not be verified” or comes from an unidentified developer.

  1. Open System Settings → Privacy & Security.
  2. Scroll down to the line about DYMO Print Desk being blocked.
  3. Click Open Anyway and confirm.

You won't see this again on this computer.

03

Set two things, once

The app opens. There are exactly two things to fill in, and it remembers both.

Pick your printer

Find the Label printer dropdown and choose your DYMO LabelWriter. It saves the moment you pick it.

Paste your Square key

Paste it into the Square API key box. It's stored securely on this computer, so you won't be asked again.

Then click Fetch inventory and your products load into the table.

Printing a label

Find the product in the table, or type a barcode by hand. Set how many labels you want, then click Print labels. The preview on the right is exactly what comes out of the printer.

Keeping it up to date

The app checks for new versions on its own and shows the result in the top-right corner, next to the version number. You can press Check now there any time.

Windows

Updates download quietly in the background. When one is ready the button changes to Restart now — click it when convenient.

Mac

The button changes to Get it and opens the download page. Install it the same way as the first time — but you won't need the Privacy & Security step again.

If something goes wrong

My printer isn't in the dropdown
Check the DYMO is plugged in and switched on, then close the app completely and open it again. The list is built when the app starts.
Nothing prints, and there's no error
The wrong printer is probably selected. Check the dropdown — if the name has (not connected) after it, that's the problem.
It says the barcode is too long
Anything over 32 characters prints too densely to scan reliably. Use a shorter code.
The app won't open at all
Restart the computer and try once more. If it still won't open, photograph the error message before clicking anything.
