Setting up DYMO Print Desk

You only do this once. After that, opening it is a double-click.

Which computer?

01

Install it

Windows

Download DYMO-Print-Desk-Setup.exe and double-click it.

It installs itself and puts a shortcut on your desktop. Nothing to choose.

Mac

Download the .dmg file and double-click it.

A window opens showing the app icon next to an Applications folder. Drag the icon onto the folder, then close the window.

Two Mac downloads are offered. Pick arm64 for any Mac from 2020 onward, or the other for older Intel Macs. Not sure? Apple menu → About This Mac. If it says Apple M1, M2, M3 or M4, you want arm64.

02

Get past the security warning

This warning is expected, and it only appears once. It shows up because the app doesn't carry a paid security certificate yet — not because anything is wrong with it.

Windows

A blue box says “Windows protected your PC.”

  1. Click More info — it's small text inside the box, easy to miss.
  2. Click Run anyway.
Mac

A box says the app “could not be verified” or is from an unidentified developer.

  1. Open System Settings → Privacy & Security.
  2. Scroll down to the line about DYMO Print Desk being blocked.
  3. Click Open Anyway and confirm.

You won't see this again on this computer.

03

Set two things, once

The app opens. There are exactly two things to fill in, and it remembers both.

Pick your printer

Find the Label printer dropdown and choose your DYMO LabelWriter from the list. It saves as soon as you pick it.

Paste your Square key

Paste it into the Square API key box. It's stored securely on this computer, so you won't be asked for it again.

Then click Fetch inventory. Your products load into the table.

Printing a label

Find the product in the table, or type a barcode by hand. Set how many labels you want, then click Print labels.

The preview on the right is exactly what comes out of the printer — 28 × 89 mm, barcode running down the length of the label.

If something goes wrong

My printer isn't in the dropdown
Check the DYMO is plugged in and switched on, then close the app completely and open it again. The list is built when the app starts.
Nothing prints, and there's no error
The wrong printer is probably selected. Check the dropdown — if the name has (not connected) after it, that's the problem.
It says the barcode is too long
Anything over 32 characters prints too densely to scan reliably. Use a shorter code.
The app won't open at all
Restart the computer and try once more. If it still won't open, take a photo of the error message before clicking anything.

Updates

Windows

Updates install themselves quietly in the background. There is nothing for you to do.

Mac

A message appears when a new version is ready, with a Download button. Install it the same way as the first time — but you won't need the Privacy & Security step again.
